# Models

Every model reported for the week of 2026-11-09, as its record's runs were trained: the settings come from each run's `spec.json` and the parameters from its `efficiency.json`. Every model reads a spectrogram. The pretrained encoders stay frozen; their heads read one layer's frames, chosen on validation by an SVM probe of every layer. The protocol is in [protocol.md](protocol.md).

## The SVM probes

Each SVM reads one layer's mean vector per utterance, normalized per speaker, with an RBF kernel; C and gamma are chosen on each fold's validation set.
